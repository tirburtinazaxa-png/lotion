# WormGPT Telegram Bot

Точная копия WormGPT v5.2 в Telegram с интегрированной панелью управления.

## 🚀 Быстрый старт

### 1. Деплой на Railway

1. Создайте репозиторий на GitHub и загрузите все файлы.
2. Зарегистрируйтесь на [railway.app](https://railway.app).
3. Создайте новый проект и выберите ваш репозиторий.
4. Railway автоматически определит Python и установит зависимости.
5. Добавьте переменные окружения в настройках проекта:
 - `TELEGRAM_BOT_TOKEN`: Ваш токен
 - `WEBHOOK_URL`: URL вашего деплоя (сгенерируется автоматически)
 - `WORMGPT_API_KEY`: Ваш ключ API

## 📱 Функции

- 🤖 Полная копия WormGPT v5.2
- 🌐 Интегрированная панель управления
- 💾 История сообщений в SQLite
- 📊 Статистика использования
- 🌍 Русский язык

## 🛠️ Технологии

- Python 3.10+
- FastAPI
- Telegram Bot API
- SQLite
- Docker
